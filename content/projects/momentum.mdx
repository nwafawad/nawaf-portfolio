## The problem

Traditional technical screening often leans on résumé keywords or subjective review. Momentum evaluates candidate work samples against explicit rubrics and returns evidence-backed competency scores, gaps, and recommended learning tracks.

## Making model output dependable

Generative output is useful only if the rest of the product can trust its shape. I defined Pydantic contracts for scores, evidence snippets, gap analysis, and recommended tracks, then enforced the same schema through the Gemini API. Validated results can be rendered and persisted without brittle markdown parsing.

<Decision title="FastAPI for asynchronous AI orchestration">
  Model calls are I/O-bound and may take seconds. Async route handlers and a
  non-blocking HTTP client let the service await inference without tying up a
  worker thread, while Pydantic provides request and response validation at the
  API boundary.
</Decision>

## Auditability and delivery

Supabase stores candidate benchmarks, model parameters, prompts, and resulting scores as an audit trail. Cached evaluations returned in under 150 ms in testing, and strict validation eliminated parsing failures in the tested pipeline. Docker Compose packages the client, API, and local service dependencies into a reproducible setup.
