## Project overview

Built in March 2026, RECYX is a full-stack platform for digital transactions and circular-economy commerce. The project connects a React.js interface to a Python API and a relational PostgreSQL data layer.

<ProjectArtifact variant="recyx" caption="RECYX connects the client, API, and relational data layer in one full-stack application." />

## Application stack

The backend uses FastAPI with SQLAlchemy ORM and PostgreSQL. The frontend is built with React.js, keeping the interface and service layers within a modern web application stack.

<Decision title="Testing on both sides of the stack">
The project uses pytest for Python testing and Jest for JavaScript testing, providing automated coverage across the application.
</Decision>

## What the project demonstrates

RECYX demonstrates full-stack application development, REST API implementation, relational data modeling, ORM-based persistence, frontend integration, and automated testing.
