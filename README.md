# Nawaf Ahmed — Portfolio

An editorial software-engineering portfolio built with Vinext/Next.js, React,
TypeScript, and MDX content files.

## Development

```bash
npm run dev
```

## Content

Project and experience entries live in `content/projects/*.mdx`. The downloadable
résumé is generated by `scripts/build-resume.mjs` and published from
`public/resume.pdf`.

## Production

```bash
npm run build
```
