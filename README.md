# Nawaf Ahmed — Portfolio

An editorial software-engineering portfolio built with Vinext/Next.js, React,
TypeScript, and MDX content files.

## Development

```bash
npm run dev
```

## Content

Project and experience entries live in `content/projects/*.mdx`. The downloadable
résumé is generated by `scripts/build-resume.mjs` and published from
`public/resume.pdf`.

Case studies use a small, static renderer supporting paragraphs, `##` headings,
inline code, `<Decision>` callouts, and single- or multiline `<ProjectArtifact />`
blocks. These files are not evaluated as arbitrary MDX.

Optional frontmatter fields `displayOrder` and `repositoryUrls` control project
ordering and GitHub source links. Source snapshots and attribution notes are
recorded in [docs/project-evidence.md](docs/project-evidence.md).

## Production

```bash
npm run build
```
