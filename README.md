# Nawaf Ahmed — Portfolio

An editorial product-design portfolio built with Vinext/Next.js, React,
TypeScript, and MDX content files.

## Development

```bash
npm run dev
```

## Content

Case studies live in `content/projects/*.mdx`. Keep concept work labeled as
concept work, and replace the placeholder résumé before sharing it externally.

## Production

```bash
npm run build
```
