## Data and API work

I design normalized relational schemas with referential integrity, deliberate indexes, and audit fields for structured records. At the service boundary, typed DTO validation and role-based access control keep incoming data and permissions explicit.

<Decision title="Normalize first, then measure">
  Third-normal-form schemas reduce duplication and make record ownership clear.
  When multi-table joins began to slow, I used query plans to target composite
  foreign-key and status indexes; test workloads held P95 latency below 85 ms
  without denormalizing the model.
</Decision>

## Reproducible delivery

Docker Compose packages application runtimes and isolated PostgreSQL services so branches share the same topology locally and in staging. Git branches, focused commits, and organized documentation keep changes reviewable and auditable.

## Collaboration

The role requires close collaboration across a fast-moving team. I treat API contracts, migration notes, and repository hygiene as part of the engineering work—not cleanup after it.
